# WA-Radar-Server - رادار الرسائل المحذوفة في واتساب

<img src="https://img.shields.io/badge/Node.js-18+-green.svg" alt="Node.js Version"/>
<img src="https://img.shields.io/badge/License-ISC-blue.svg" alt="License"/>

## 📖 عن المشروع
سيرفر خلفي (Backend) يقوم بالاتصال بحساب واتساب الخاص بك، ومراقبة جميع الرسائل النصية الواردة. عندما يقوم أي شخص بحذف رسالة نصية ("حذف للجميع")، يقوم السيرفر فورًا بإرسال تفاصيل تلك الرسالة (المرسل، النص، الوقت) إلى بوت تيليجرام خاص بك.

**ملاحظة هامة:** الإصدار الحالي **يدعم فقط تتبع الرسائل النصية**. لا يدعم تتبع الملفات أو الصور أو الفيديوهات المحذوفة.

## 🛠️ التقنيات المستخدمة
- **Node.js** (>=18.0.0)
- **whatsapp-web.js** (للتفاعل مع واتساب)
- **Puppeteer** (لمحاكاة المتصفح)
- **Telegram Bot API** (لإرسال التنبيهات)
- **QRCode** (لإنشاء رمز QR لتسجيل الدخول)

## 🚀 طريقة التشغيل (للمطورين)

### المتطلبات الأساسية
- تثبيت [Node.js](https://nodejs.org/) (الإصدار 18 أو أحدث)
- حساب بوت تيليجرام و `TG_TOKEN` (احصل عليه من [@BotFather](https://t.me/BotFather))
- معرف الدردشة (`TG_CHAT_ID`) (احصل عليه من [@userinfobot](https://t.me/userinfobot))
